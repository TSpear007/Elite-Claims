# Claimant pivot examples

Need proof → provide official source and encourage independent verification.
Scam concern → request no sensitive data; identify private-company status; provide government source.
Self-claim → confirm that option and explain optional service value.
Fee concern → show only VERIFIED fee and claimant net/direct option.
Not interested → offer public-record reference or no further contact once.
Callback → honor requested time.
Do not contact → no pivot; suppress immediately.
