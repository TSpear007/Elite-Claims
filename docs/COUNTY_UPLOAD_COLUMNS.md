# Standard county import columns

Required: `state`, `surplus_amount`.

Recommended: `county`, `claimant_name`, `case_number`, `parcel_number`, `property_address`, `sale_date`, `deadline_date`, `external_id`.

Source metadata is recorded separately: agency, source name, official URL, source type and retrieval date. Raw row data is retained for traceability while normalized fields drive search/scoring.
