# Why the fee engine is jurisdiction-specific

Examples from official authorities show materially different structures: Texas Tax Code §34.04 contains a prohibition on non-attorney fees for covered owner excess-proceeds recovery; Arizona §33-812(P) has a 30-day timing rule and a $2,500 reasonableness threshold; Nevada's 2025 enactment includes a 10% limit for covered arrangements. Florida distinguishes tax-deed surplus from mortgage-foreclosure surplus. These are examples for configuration design, not a complete 50-state legal survey.
